# Хто продає електроенергію державі: закупівлі в Prozorro

Збір і аналіз закупівель електроенергії (CPV 09310000-5) державними і комунальними замовниками з 1 січня 2025 року.
Результат — звіт `docs/index.html` і CSV-таблиці в `data/`:
- рейтинг постачальників за юрособами (назва + ЄДРПОУ) і за групами компаній;
- середня ціна кіловат-години в кожного постачальника;
- договори, де ціна кіловат-години після додаткових угод зросла більш як на 10%;
- великі договори і тендери з великою очікуваною вартістю;
- розподіл за типами замовників (медицина, освіта, силові органи, комунальні підприємства тощо) і за власністю
  (державна / комунальна).

Кожен рядок має посилання на тендер на prozorro.gov.ua.

## Запуск

1. **Actions → «Оновлення даних про закупівлі електроенергії» → Run workflow**:
   - спершу `probe` — діагностика за один місяць (кілька хвилин): скільки результатів дає пошук і які типи процедур він індексує;
   - потім `all` — повний збір. Електроенергію купують десятки тисяч замовників, тож перший збір займає кілька запусків
     (кожен до 5 годин). Якщо запуск не встигає, він зберігає прогрес і **сам запускає продовження** (`resume`),
     до 10 разів поспіль.
2. Далі дані оновлюються автоматично щовівторка.
3. Звіт — файл `docs/index.html`: відкрийте його в репозиторії → «Download raw file» → відкрийте в браузері.
   GitHub Pages для приватних репозиторіїв доступний лише на платних тарифах.

Локально: `python3 power.py probe`, `python3 power.py all` (Python 3.10+, без залежностей).

## Що де лежить

| Файл | Що містить |
|---|---|
| `config.json` | період, CPV, пороги «великих» договорів, правила груп замовників і визначення власності |
| `overrides/buyers.csv` | ручне віднесення замовника до групи за ЄДРПОУ (`group` = id групи або `exclude`) |
| `overrides/suppliers.csv` | ручне об'єднання постачальників у групи компаній (`edrpou,holding,note`) — після перевірки за реєстрами |
| `data/contracts.csv` | усі договори: замовник, постачальник, суми, обсяг у кВт·год, ціна при підписанні і поточна, допугоди |
| `data/suppliers_active_2026.csv` | рейтинг юросіб за договорами, що діють у 2026 році |
| `data/holdings_active_2026.csv` | те саме, з об'єднанням у групи компаній за `overrides/suppliers.csv` |
| `data/suppliers_signed_since_start.csv` | рейтинг за всіма договорами з початку періоду |
| `data/tenders.csv` | усі тендери з очікуваною вартістю і очікуваною ціною кВт·год |
| `data/buyers.csv` | замовники, група, власність і підстава віднесення |
| `data/raw/` | скорочені відповіді API (лише потрібні поля), по файлу на місяць |

## Методологія

**Відбір.** Пошук prozorro.gov.ua за CPV 09310000-5 за датою оголошення з 1 січня 2025 року. За повними даними
перевіряється, що в тендері й договорі є позиції електроенергії. Пошук індексує конкурентні процедури (відкриті торги,
спрощені закупівлі, запити цінових пропозицій); **прямі договори, оприлюднені звітом, і переговорні процедури до вибірки
не потрапляють.**

**Сума.** Поточна вартість договору з модуля договорів (з урахуванням додаткових угод); для розірваних — фактично
сплачена сума, якщо її вказано. Переважно з ПДВ.

**Ціна кВт·год.** Сума договору, поділена на обсяг електроенергії в кВт·год (МВт·год перераховуються). Ціна при
підписанні — з початкових умов, поточна — з умов після допугод. Обсяг — запланований, а не фактично спожитий.
Помилки замовників в одиницях виміру дають хибні ціни, тому підозрілі значення варто перевіряти за посиланням.

**«Діють зараз».** Договір не позначений як виконаний чи розірваний, і строк його дії ще не минув на дату оновлення.

**«Діяли у 2026».** Договір, строк дії якого закінчується 1 січня 2026 року або пізніше; якщо строк не вказано —
підписаний у 2026 році.

**Групи замовників і власність** визначаються за назвою за правилами в `config.json` — це наближення.
Помилки виправляються в `overrides/buyers.csv`, а `data/buyers.csv` показує підставу кожного віднесення.

Дані: Prozorro, відкриті дані з правом вільного повторного використання за умови посилання на джерело.
